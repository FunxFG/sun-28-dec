<product_requirements>
The goal is to build an advanced Austroads-compliant Traffic Management Plan (TMP) and Traffic Guidance Scheme (TGS) generator. The application must minimize manual user input by auto-populating form data from various SA Government APIs (traffic volumes, crash data, road attributes, etc.).

Key requirements driven by user feedback include:
1.  **Dynamic UI:** The input form should hide fields that can be auto-populated. A Review button must allow the user to inspect the fetched data in a collapsible panel before generating the TMP.
2.  **Professional PDF Output:** The final TMP document must be a multi-page, professional PDF that includes all auto-populated data, risk assessments, and compliance details derived from uploaded SA DIT Field Guides. This includes new sections for dilapidation reports, permit checklists, and detailed safety analyses.
3.  **High-Fidelity Visual TGS:** The TGS must be a visual diagram, not just text. It must overlay actual traffic sign images (not just markers) onto high-resolution Google Maps satellite imagery. It must accurately depict the street layout, work zone, and any detour routes with clear visual paths and arrows.
4.  **Persistent Storage:** All generated files (TMP PDFs, TGS images/PDFs, and supplementary documents like signage schedules) must be saved to the server's file system () and be accessible for download via a dedicated API endpoint.
</product_requirements>
